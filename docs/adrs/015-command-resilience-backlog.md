# ADR-015: Command Resilience + Backlog System

## Status
Accepted

## Date
2026-03-26

## Context

In long-context AI sessions, agent compliance with framework directives (TDD, changelog, security, versioning) degrades as the conversation grows. The full constitution and TYREX.md scroll out of the agent's effective attention window, leading to missed steps.

Additionally, the framework lacked a structured way to capture, organize, and mature ideas before they become features. Users had ideas scattered across conversations with no persistent, organized backlog.

Finally, commands ended abruptly without suggesting the next logical step, forcing users to remember the workflow.

## Decision

### 1. Guardrails Inline (BL-002)
Create a compact 10-rule constitution summary (`templates/commands/shared/guardrails-inline.md`) that executor commands reference before each task. Self-contained, ~120 tokens vs ~2000 for full constitution re-read.

### 2. Checkpoint Reminder System (BL-001)
Create a periodic directive refresh (`templates/commands/shared/checkpoint-reminder.md`) injected every N tasks (default: 2, configurable via `tyrex.yml quality.checkpoint_interval`). Checklist format that verifies compliance before proceeding.

### 3. Next-Action Suggestions (BL-004)
Create a command flow map (`templates/commands/shared/next-action-map.md`) that every command references at completion. Suggests the next logical command with session context. Structured choices: execute now, different command, or done.

### 4. Backlog Command (BL-007)
Create `/tyrex-backlog` with subcommands: add, edit, remove, view, plan, pick. Items stored in `.tyrex/backlog/items/BL-NNN.yml` with lifecycle: draft → ready → in-progress → done. Ready requires explicit human confirmation (never automatic). Epics group related items. ROADMAP.md generated by `plan` subcommand.

**Backlog ≠ Feature.** Backlog is maturation; Feature is execution commitment. Items become features when picked.

## Consequences

- Command count: 23 (was 22)
- 3 new shared templates for command resilience
- Token cost of guardrails: ~120 tokens per task start (vs ~2000 for full re-read)
- Checkpoint interval configurable — can be tuned per project complexity
- Every command now has a next-action suggestion — continuous flow
- Backlog system enables structured idea management before feature commitment
- Integration points prepared for future phases: discuss↔backlog, review→backlog, quick --backlog
