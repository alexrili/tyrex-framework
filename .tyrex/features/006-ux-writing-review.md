# Feature 006: UX Writing Skill & Text Review

## Summary
Create a copywriter skill persona and perform a comprehensive review of all user-facing text in the Tyrex Framework to ensure consistency, clarity, and a professional tone.

## Voice & Tone
- **Professional and direct** — concise, no filler. Style reference: Stripe, Vercel.
- Active voice, actionable messages, consistent terminology.

## Tasks
1. Create `copywriter.md` skill template
2. Generate UX Writing Audit Report (all ~246 touchpoints)
3. Apply text improvements to `bin/tyrex.js` (CLI)
4. Apply text improvements to command files (18 `.md` files)
5. Update CHANGELOG and TYREX.md

## Out of Scope
- i18n / internationalization (separate future feature)
- Translating any content to non-English languages
- Changing command behavior or logic
- Adding new commands or features
