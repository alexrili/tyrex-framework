# Security Audit - Tyrex Framework

> Generated by `/tyrex-init` on 2026-03-07
> Overall Risk: **LOW**

## Executive Summary

Tyrex is a lightweight CLI tool with zero runtime dependencies, no network communication, no server, no database, and no authentication layer. The attack surface is minimal. 3 findings identified, none critical.

## Findings

| # | Status | Severity   | Category           | File             | Line | Description |
|---|--------|------------|--------------------|------------------|------|-------------|
| 1 | [ ]    | **MEDIUM** | Environment Files  | `.gitignore`     | —    | `.env` files not excluded from git tracking |
| 2 | [ ]    | **LOW**    | Code Patterns      | `bin/tyrex.js`   | 102  | Unescaped string in `new RegExp()` constructor (not currently exploitable — keys are hardcoded) |
| 3 | [ ]    | **LOW**    | Code Patterns      | `bin/tyrex.js`   | 378  | `fs.rmSync` recursive deletion without path containment check (not currently exploitable — paths are hardcoded) |

## Recommended Fixes

### 1. Add `.env` to `.gitignore`

```
.env
.env.*
!.env.example
```

### 2. Escape regex in template replacement (bin/tyrex.js:102)

```javascript
// Use replaceAll (Node 15+) instead of RegExp
content = content.replaceAll(`{{${key}}}`, value);
```

### 3. Add path containment check (bin/tyrex.js:378)

```javascript
const resolved = path.resolve(commandsDir);
const resolvedTarget = path.resolve(targetDir);
if (!resolved.startsWith(resolvedTarget + path.sep)) {
  throw new Error(`Refusing to delete path outside target: ${resolved}`);
}
```
